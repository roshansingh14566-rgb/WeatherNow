
# 🌦️ WeatherNow

A modern, responsive weather dashboard built with React and Vite. Search for a city and explore current weather conditions through a clean interface with dynamic weather backgrounds.

## 🚀 Live Demo

**[Open WeatherNow](https://weathernow-roshan.vercel.app/)**

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Switch between Celsius and Fahrenheit
- 🌤️ Dynamic video backgrounds based on weather conditions
- 📍 Current-location weather lookup
- 💧 Humidity, wind speed, pressure and visibility
- 🌅 Sunrise and sunset information
- 📅 Five-day weather forecast
- 🕘 Recent city searches
- 📱 Responsive layout for mobile and desktop
- ⏳ Loading animation while fetching weather data

## 🛠️ Built With

- React
- JavaScript
- Vite
- HTML5
- CSS3
- OpenWeather API

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/roshansingh14566-rgb/WeatherNow.git
```

### 2. Open the project folder

```bash
cd WeatherNow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure your API key

Create a `.env` file in the project root and add your OpenWeather API key using the same variable name expected by the application.

```env
VITE_WEATHER_API_KEY=your_api_key_here
```

Replace `your_api_key_here` with your own API key. Never upload your real `.env` file or API key to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
